# Security Policy

## Supported Versions

Security updates are currently provided for the latest `main` branch only.

| Version | Supported |
| ------- | --------- |
| `main`  | Yes       |
| Older commits/releases | No |

## Reporting a Vulnerability

If you discover a security issue, please report it privately and do not open a public GitHub issue.

- Preferred channel: GitHub Security Advisories (private report)
- Fallback: contact repository owner directly

When reporting, include:

- A clear description of the issue
- Steps to reproduce
- Impact assessment
- Suggested fix (if available)

## Response Process

- Initial triage target: within 72 hours
- Status update target: within 7 days
- Fix timeline: depends on severity and complexity

## Disclosure Policy

- Please allow time for investigation and patching before public disclosure.
- After a fix is released, coordinated disclosure is welcome.

## Scope Notes

This repository includes:

- Frontend (React/Vite)
- Backend (Node.js/Express/Prisma)
- CI/CD workflows (GitHub Actions)

Security findings in dependencies should be reported as well, especially if they impact runtime usage.
