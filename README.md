# MET - Micro Economics Tool (MET) 🚀

**MET** is a professional, high-performance micro-economics tool designed to track your financial inflows and outflows with a modern, "flashy" interface.

Built with **Gemini AI Technology** for **Trysha-rbrn**.

---

## 🛠️ Tech Stack
- **Frontend:** React (Vite + TypeScript), TailwindCSS 4, Lucide Icons, Axios.
- **Backend:** Node.js (Express + TypeScript), JWT Auth, Bcrypt.
- **Database:** PostgreSQL with Prisma ORM.
- **Infrastructure:** Docker Compose (for local database).

---

## 🚀 Prve instrukcije (Startuj projekat pre sesije)

Pre nego što započneš rad u terminalu sa mnom, uradi sledeće korake:

1.  **Pokreni Bazu (Docker):**
    U korenu projekta (tamo gde je `docker-compose.yml`) kucaj:
    ```bash
    docker compose up -d
    ```
2.  **Pokreni Backend:**
    Idi u `backend` folder i pokreni server:
    ```bash
    cd backend
    npm run dev
    ```
3.  **Pokreni Frontend:**
    Otvori **novi terminal**, idi u `frontend` folder i pokreni aplikaciju:
    ```bash
    cd frontend
    npm run dev
    ```
4.  **Otvori u Browseru:**
    Idi na `http://localhost:5173`

## 💎 Features
- **Modern Auth:** Secure Login/Register with JWT.
- **Transactions:** Full CRUD with metadata support.
- **Categories:** Hierarchical categories (Categories & Subcategories).
- **Theme:** Dynamic Light/Dark mode.
- **Settings:** Profile management (Name, Password, Account Deletion).
- **Currencies:** Real-time currency support (USD, EUR, CAD, RUB, RSD, TRY).
