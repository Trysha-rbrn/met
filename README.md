# MET - Micro Economics Tool (MET)

**MET - Micro Economics Tool** is a modern full-stack application designed to help users track their personal finances (inflows and outflows).

## Features
- **Multi-user Authentication:** Secure login and registration.
- **Transaction Tracking:** Track income and expenses.
- **Dashboard:** Visual insights into spending habits with charts.
- **Theme Support:** Switch between Light and Dark mode.

## Tech Stack
- **Frontend:** React (Vite + TypeScript), TailwindCSS, Chart.js.
- **Backend:** Node.js (Express + TypeScript).
- **Database:** PostgreSQL with Prisma ORM.
